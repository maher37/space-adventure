# Space Adventure (working title)

A comedy point-and-click adventure: Space Quest silliness, Monkey Island controls.

## Play it
1. Install **Godot 4.7.2** (standard version, not .NET) from godotengine.org.
2. Open Godot, choose **Import**, and pick this folder's `project.godot`.
3. Press **F5** (or the ▶ Play button, top right).

## Room one: the Galley
You are Dex, Third-Class Snack Restocker. Get onto the bridge.
Spoiler-free hint: everything lost on a ship ends up in the same place.
Also: don't push the button. Or do. That's what the "Try again" button is for.
